<p>
  This application is a backend system built to handle API requests and perform appropriate database operations upon successful request. The purpose of this project is demonstrate understanding in SOLID principles, and to implement a clean, fully functional application with the aim to reinforce industry standard practices. Since this application is built upon RESTful APIs, these endpoints are intended to be consumed by a client application which can and will be demonstrated in another project solution.
</p>
